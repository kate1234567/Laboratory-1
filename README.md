# Transport Racing Simulator

## Описание

Проект представляет собой симулятор гонок, разработанный на C# с использованием объектно-ориентированного программирования.

Пользователь может создавать различные типы гонок, выбирать дистанцию, регистрировать участников и определять победителя.

В проекте реализованы различные виды транспорта с индивидуальными характеристиками движения и отдыха.

Проект выполнен в рамках лабораторной работы по дисциплине «Объектно-ориентированное программирование».

## Используемые технологии

- C#
- .NET
- Windows Forms

## Основные возможности

- создание гонки;
- выбор дистанции;
- регистрация участников;
- поддержка наземных, воздушных и смешанных гонок;
- расчет времени прохождения дистанции;
- определение победителя;
- поддержка погодных условий.

## Использованные принципы ООП

- наследование;
- полиморфизм;
- абстрактные классы;
- интерфейсы;
- инкапсуляция.

## Реализованные транспортные средства

- Ступа Бабы Яги
- Метла
- Сапоги-скороходы
- Карета-тыква
- Ковер-самолет
- Избушка на курьих ножках
- Кентавр
- Летучий корабль

## Запуск проекта

1. Открыть решение `RacingNet.sln` в Visual Studio.
2. Запустить приложение.
3. Выбрать параметры гонки и участников.
